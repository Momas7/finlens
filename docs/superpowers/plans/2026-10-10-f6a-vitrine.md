# F6a — Vitrine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Conta demo gerada pela API, Docker de um comando, mídia reproduzível e README de vitrine.

**Architecture:** `@finlens/demo-seed` (gerador puro + executor sobre um `client` HTTP abstrato); uma imagem Docker para todos os serviços do perfil `demo`; script Playwright de mídia separado da suíte.

**Tech Stack:** TypeScript, Fastify inject (teste), Docker/Podman Compose, Next.js standalone não usado (imagem única), Playwright, ffmpeg.

**Spec:** `docs/superpowers/specs/2026-10-10-f6a-vitrine-design.md`

## Global Constraints

- Conta demo `demo@finlens.local` / `demo-finlens-123`; dados fictícios; valores "apenas local" sinalizados.
- Seed só pela API; idempotente; determinístico; nenhuma data futura.
- Sem `Co-Authored-By` nem rodapé de ferramenta. Nada de dados reais no repositório.

## Review Focus

1. **Seed rodando no dia 1 do mês**: duplicata exige dois dias — plantar no dia 1 do mês corrente e no último dia do mês anterior não serve (insight é do mês); no dia 1, plantar duplicata no mesmo dia 1 (≤ 2 dias vale). — Task 1 teste com `today = '2026-11-01'`.
2. **Limite de requisições**: ~300 POSTs; perfil demo define `RATE_LIMIT_PER_MINUTE=5000`. — Task 3.
3. **Rewrites do Next com `API_URL` em tempo de build**: imagem builda com `API_URL=http://api:3333`. — Task 3 verificação.
4. **Seed rodando de novo após `compose up` repetido**: `{ created: false }`, exit 0. — Task 2.
5. **Rótulo de categoria inexistente**: falha cedo com mensagem clara. — Task 1/2.
