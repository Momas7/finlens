# F4a — Painel do mês Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Início vira o painel do mês: quanto sobrou, régua da renda gasta com comparação, para onde foi e últimos 6 meses.

**Architecture:** Funções puras de mês/percentual em `packages/domain/src/analytics`; a API agrega em SQL sob RLS e devolve `MonthSummary` pronto; a web desenha com SVG/HTML no servidor, sem JS no cliente.

**Tech Stack:** Fastify 5 + Zod 4 + Drizzle (Postgres 17, RLS), Next.js 16 Server Components, Vitest, Playwright + axe.

**Spec:** `docs/superpowers/specs/2026-10-08-f4a-painel-design.md`

## Global Constraints

- Dinheiro em bigint centavos; na API, string (`TotalCents`).
- Mês civil no fuso de São Paulo (`todayInSaoPaulo`).
- Categoria `kind = 'movement'` fora de entradas e saídas; sem categoria conta.
- Raiz = `coalesce(parent_id, id)`; arquivadas continuam somando.
- Nenhum gráfico com JS no cliente; cada gráfico com tabela equivalente `sr-only`; barras `aria-hidden`.
- Textos fixos: "Sobrou em {mês}" / "Faltou em {mês}", "Entrou", "Saiu", "{p}% da renda gasta", "Sem entradas neste mês.", "Para onde foi", "Outras {n} categorias", "Sem categoria", "{n} a revisar", "Últimos 6 meses", "Nada lançado em {mês}.", "Mês inválido, mostrando {mês}", "Não foi possível carregar o resumo agora.".
- Sem `Co-Authored-By` nem rodapé de ferramenta em commits/PR.

## Review Focus

1. **Virada de ano** (`?mes=2026-01`): anterior é dezembro de 2025, histórico atravessa o ano. — Task 1 (`lastMonths('2026-01', 6)`) e Task 2 (histórico em janeiro).
2. **Dia 31 no mês corrente com mês anterior de 30 dias**: comparação até o último dia do anterior, sem data inválida no SQL. — Task 1 (`comparisonCutoff`).
3. **Estorno** (valor positivo numa categoria de despesa): conta como entrada, não reduz saída — regra simples e explícita. — Task 2 (teste "estorno conta como entrada").
4. **Categoria raiz sem filhas recebendo lançamento direto e filha arquivada** somam na mesma raiz. — Task 2.
5. **`?mes=` lixo na URL** (`2026-13`, `abc`, futuro): página não quebra, mostra aviso. — Task 3 (e2e).

### Task 2: API — resumo do mês e filtro por raiz

**Files:** Create `packages/contracts/src/analytics.ts`, `apps/api/src/modules/analytics/{queries,routes}.ts`, `apps/api/test/analytics.integration.test.ts`; Modify `packages/contracts/src/index.ts`, `apps/api/src/app.ts`, `apps/api/src/modules/transactions/repository.ts`, `apps/api/test/transactions.integration.test.ts`.

**Interfaces:**
- Consumes: Task 1.
- Produces: contrato `MonthSummary` (forma da spec; `incomeCents`/`expenseCents`/`netCents` como `TotalCents`; `categories[].categoryId: Uuid | null`; `count`/`pendingReview`: int); `MonthQuery = { month?: string }`. Rota `GET /v1/analytics/month`.
- `loadMonthSummary(tx: Tx, month: Month, today: string): Promise<MonthSummary>` em `queries.ts`. `pendingReview` = contagem de `classification_status in ('suggested','none')` (mesmo critério de "precisam de você").
- Validação: `month` ausente → mês de `todayInSaoPaulo()`; `parseMonth` nulo ou `month > mês corrente` → 400 `validation` com `fields.month = 'Use um mês no formato AAAA-MM, até o mês atual.'`.

Agregação (decisão): um `select` agrupado por mês e raiz para o período `lastMonths(month,6)[0]`..`monthRange(month).to`, com `left join categories c on c.id = t.category_id` e `where c.kind is distinct from 'movement'`; somas `sum(case when amount>0 ...)` e `sum(case when amount<0 then -amount ...)`; o total do mês, as categorias e o histórico saem dessa mesma consulta em TS. A comparação é uma segunda consulta somada no intervalo `monthRange(prev).from`..(`comparisonCutoff` no mês corrente, senão `monthRange(prev).to`). Rótulo da raiz: nome da raiz (busca nas categorias, inclusive arquivadas).

### Task 3: Web — painel do mês

**Files:** Create `apps/web/src/app/painel/month-summary/{headline,where-it-went,history-chart}.tsx`, `apps/web/src/lib/month-label.ts` (+ `.test.ts`), `apps/web/e2e/painel.spec.ts`; Modify `apps/web/src/app/painel/page.tsx`, `apps/web/e2e/a11y.spec.ts`, `apps/web/e2e/helpers.ts` (helper `addIncome`).

**Interfaces:**
- Consumes: `MonthSummary` (Task 2); `parseMonth`, `previousMonth`, `nextMonth`, `monthRange`, `spentShare`, `deltaPoints` (Task 1); `Scale` (`limit` para excesso), `Figure`, `Panel`.
- Produces: `monthLabel(month: Month): string` ("outubro de 2026"), `monthName(month): string` ("outubro"), `shortMonth(month): string` ("out").
- Página: `searchParams.mes`; inválido/futuro → busca o mês corrente e mostra aviso; erro da API (não 401) → painel com "Não foi possível carregar o resumo agora."; sem contas ou sem nenhum lançamento em todo o histórico → convite atual.
- Régua: `Scale` com `value = share*100`, `max = 100`, `limit = 100`; marca de comparação desenhada sobre a régua em `left: previousShare*100%` (limitada a 100%) com `aria-hidden`; leitura acessível no `valueText`.
- Para onde foi: 6 maiores + "Outras N categorias" (sem link); link `/painel/transacoes?categoryId={id}&from={from}&to={to}` com nome acessível "{label}, R$ X"; "Sem categoria" → `/painel/revisao`.
