# F5b — Metas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Metas vinculadas a uma conta, com progresso pelo saldo, ritmo, previsão com rendimento opcional e aporte necessário para uma data.

**Architecture:** Matemática pura em `packages/domain/src/goals`; tabela `goals` sob RLS; API calcula saldos de fim de mês e monta o `Goal`; tela `/painel/metas` com Server Actions.

**Tech Stack:** TypeScript, Drizzle/Postgres RLS, Fastify, Next.js 16, Vitest, Playwright + axe.

**Spec:** `docs/superpowers/specs/2026-10-09-f5b-metas-design.md`

## Global Constraints

- Fórmulas e limites da spec (600 meses, `n < 1 → 1`, ceil em centavos, taxa em pontos-base 0–10000, string % com até 2 casas 0–100).
- Uma meta ativa por conta (índice parcial); cartão não pode.
- Textos fixos da spec.
- RLS ENABLE+FORCE em migração própria.
- Sem `Co-Authored-By` nem rodapé de ferramenta.

## Review Focus

1. **Conta arquivada vinculada a meta ativa**: meta continua listada com o saldo; não quebra. — Task 3 teste.
2. **Taxa 0% informada** (≠ nula): comporta-se como sem taxa, sem divisão por zero. — Task 1.
3. **Alvo menor que o saldo ao editar**: vira `done`, `remainingCents '0'`, progresso 1. — Task 3.
4. **Lançamento com data futura na conta**: entra no saldo atual (mesma regra de contas), não nos fins de mês passados. — Task 3.
5. **Saldo negativo** (conta corrente no vermelho): progresso 0, previsão segue a fórmula. — Task 1.
