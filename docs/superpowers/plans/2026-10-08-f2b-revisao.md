# F2b — Revisão, propagação e regras sugeridas — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Caixa de revisão agrupada, confirmação em lote, oferta de propagação para lançamentos parecidos e regras sugeridas a partir de confirmações consistentes.

**Architecture:** Lógica de sugestão de regra pura em `packages/domain`; agrupamento, semelhantes e lote como consultas SQL sob RLS em módulos Fastify (`review`, `transactions`, `rule-suggestions`); telas Next com Server Components e Server Actions. Única tabela nova: `rule_suggestion_dismissals`.

**Tech Stack:** TypeScript, Drizzle + PostgreSQL 17 (`pg_trgm`, RLS), Fastify 5 + Zod 4, Next.js 16, Vitest, Playwright + axe.

**Spec:** `docs/superpowers/specs/2026-10-08-f2b-revisao-design.md`

## Global Constraints

- Chave: `merchant_key` ou, sem ela, `description_normalized`; sempre com sinal (`out`/`in`). Descrição normalizada vazia nunca forma chave nem casa semelhantes.
- Pendentes: `needsYou` = `suggested` + `none`; `likely` separado. Até 100 grupos por lista, 200 ids por grupo.
- Lote: 1–200 ids; todos do workspace ou 404 sem alterar nada; categoria ativa e compatível com o sinal ou 409 sem alterar nada; feedback por lançamento alterado; confirmados já na mesma categoria ignorados.
- Semelhantes: não confirmados, mesmo sinal, fora da categoria alvo, mesma chave ou `similarity ≥ 0,60`; até 50, mais recentes primeiro.
- Regra sugerida: ≥ 3 confirmações; padrão ≥ 3 caracteres; até 10 sugestões; id estável `sha1(chave|sinal|categoria|faixa)` (hex, 16 primeiros caracteres).
- Faixas: `xs` [0, 4999], `sm` [5000, 19999], `md` [20000, 99999], `lg` [100000, ∞) em centavos absolutos.
- Textos pt-BR, identidade visual vigente; commits sem coautoria.

## Review Focus

1. **Ids repetidos no lote**: esperado deduplicar, um feedback por lançamento. — Task 3.
2. **Grupo sem sugestão** (`suggestedCategoryId` nulo): esperado seletor vazio com "Escolha a categoria" e o botão só confirma depois de escolher (API responde 400 sem categoria). — Task 5.
3. **Semelhantes de lançamento com descrição normalizada vazia**: esperado lista vazia, nunca "todos os vazios". — Task 3.
4. **Contador da navegação depois de confirmar**: esperado atualizar sem recarregar manualmente. — Task 5.
5. **Sugestão de regra cujo padrão é prefixo de outro estabelecimento** ("AMAZON" já coberto por regra existente para outra categoria): esperado ainda sugerir (a regra existente é de outra categoria), mas não duplicar uma regra igual. — Task 1.
